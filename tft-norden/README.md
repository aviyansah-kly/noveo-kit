# TFT Template 02 — NORDEN
Editorial Creative Studio / Portfolio concept for Elementor.

## Preview
This folder is isolated inside the existing Noveo deployment repository so Noveo remains untouched at root.

Pages:
- Home
- Work
- Services
- Studio
- Journal
- Contact

## Direction
Inspired by premium editorial/independent studio websites such as Midnight Office, but with original layout, copy, component structure, and visual language.

## Elementor conversion notes
- Built around container/flex/grid patterns that map cleanly to Elementor.
- Shared spacing, colors and type scales are CSS variables and can become Elementor Global Styles.
- Portfolio/Journal cards can map to Loop Grid / Posts.
- Contact form maps to Elementor Form.
- Interactions are intentionally light: reveal, hover scale, marquee and mobile nav.
